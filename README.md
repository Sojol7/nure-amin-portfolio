# MD. Nure Amin — Personal Portfolio

A responsive personal portfolio built only with vanilla HTML5, CSS3 and JavaScript.

## Assignment requirements covered
- No framework or library
- Responsive mobile/tablet/desktop layout
- JavaScript dark/light mode toggle
- JavaScript mobile navigation
- JavaScript contact-form validation
- Semantic HTML and accessible labels/controls
- GitHub Pages-ready static files

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive visual design
- `script.js` — theme, navigation and validation interactions

## Suggested 7 meaningful commits
Use these commits in order rather than one bulk commit:
1. `chore: initialize vanilla portfolio project`
2. `feat: add semantic portfolio sections and content`
3. `style: build responsive portfolio layout`
4. `feat: add dark light mode toggle`
5. `feat: add mobile navigation and form validation`
6. `fix: improve responsive spacing and accessibility`
7. `docs: add deployment and project documentation`

## Git setup
```bash
git init
git branch -M main
git add .
git commit -m "chore: initialize vanilla portfolio project"
```
Then make the remaining changes in stages and commit with the messages above.

## GitHub Pages
1. Create a public GitHub repository, e.g. `nure-amin-portfolio`.
2. Add the remote:
```bash
git remote add origin https://github.com/Sojol7/nure-amin-portfolio.git
git push -u origin main
```
3. GitHub → Settings → Pages → Source: `Deploy from a branch` → Branch: `main` → `/ (root)`.
4. Save. Your live site will be available at the GitHub Pages URL shown by GitHub.
